# Sistema de Gerenciamento de Biblioteca em C

Programa desenvolvido em C para o gerenciamento de um acervo de livros e cadastro de usuarios. O sistema permite a consulta, o cadastro de novos titulos/usuarios e a gravacao persistente dos dados em arquivos de texto.

## Funcionalidades
- Listar todos os livros cadastrados
- Cadastrar novos livros no acervo
- Listar usuarios cadastrados
- Cadastrar novos usuarios
- Salvar e carregar dados automaticamente dos arquivos `livros.txt` e `usuarios.txt`

## Como rodar o programa
1. Baixe ou clone os arquivos para o seu computador.
2. Abra o terminal na pasta onde estao os arquivos.
3. Compile o programa com o comando:
   gcc main.c -o sistema
4. Execute o programa:
   ./sistema
