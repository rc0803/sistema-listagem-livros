# Sistema de Listagem de Livros em C

Programa desenvolvido em C para o gerenciamento de um acervo de livros e mangás. O sistema permite a consulta, o cadastro de novos títulos e a gravação persistente dos dados em arquivo.

## Funcionalidades
- Listar todos os livros cadastrados
- Cadastrar novos livros no acervo
- Salvar e carregar dados automaticamente do arquivo `livros.txt`

## Como rodar o programa
1. Baixe ou clone os arquivos para o seu computador.
2. Abra o terminal na pasta onde estão os arquivos.
3. Compile o programa com o comando:
   gcc main.c -o sistema
4. Execute o programa:
   ./sistema
